# Christina Mulualem — Grade 12 Student Portfolio

A student portfolio website for **Christina Mulualem**, Grade 12, Kings Academy.
Career interest: **Computer Engineering**.

## Project files
- `index.php` — portfolio webpage
- `config.php` — PDO database connection
- `database.sql` — creates and seeds the MySQL database
- `style.css` — responsive navy, blue and gold styling
- `Christina_Mulualem_Portfolio.pptx` — PowerPoint portfolio presentation

## Run locally with XAMPP
1. Install and open XAMPP. Start Apache and MySQL.
2. Copy this project folder into `xampp/htdocs/`.
3. Open phpMyAdmin and import `database.sql`.
4. Check the database username and password in `config.php`.
5. Visit `http://localhost/Christina_Mulualem_Student_Portfolio/`.
